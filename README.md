# QuestDojo RPG

สำนักฝึกคณิตศาสตร์แบบเกม RPG ภาคต่อของ QuestClass RPG สำหรับนักเรียนประถมปลาย–ม.ต้น
เลเวลในเกมนี้แยกจาก QuestClass RPG

## รอบ 1 (ตอนนี้): เล่นในเครื่อง
- สร้างตัวละคร: ชื่อเล่น (เปลี่ยนได้ตลอด กรองคำหยาบ) + เผ่า + ธาตุ (เลือกครั้งเดียว) ฉายาและร่างมาจาก QuestClass
- เส้นเลเวลแบบ QuestClass × 2 (Lv.99 = 1,998 EXP)
- ดันเจี้ยน 6 หัวข้อ × 3 ระดับ = 18 มอนสเตอร์ (ชุดเดียวกับ QuestClass) ดันเจี้ยนละ 10 ข้อ แบบ 4 ตัวเลือก ข้อละ 10 วินาที
  - ถูกครบ 10 ข้อ = ชนะ ได้ EXP เท่า QuestClass (1–5) แล้วมอนสเตอร์ตัวนั้นเกิดใหม่วันจันทร์ 00:00 (เวลาไทย)
  - ผิดหรือหมดเวลาข้อเดียว = โดนโจมตีและแพ้ ลองใหม่ได้ทันทีไม่จำกัด
  - ดาเมจใช้สูตร QuestClass + คริติคอล (CRIT ตามเลเวล และตอบเร็วกว่า 2.5 วินาทีมีโอกาสคริเพิ่ม 15%)
- ตารางแพ้ทางเผ่า–ธาตุ สุ่มใหม่ทุกวันจันทร์ (ทุกคนได้ตารางเดียวกัน) แจ้งผู้เล่นเมื่อเข้าเกมสัปดาห์ใหม่
- พลังงานประลอง 10 ขีด ฟื้น 1 ขีดทุก 2 ชม. 24 นาที
- สำรอง/กู้คืนตัวละครเป็นไฟล์ JSON • ไทย/อังกฤษ

## รอบ 2: เซิร์ฟเวอร์ (Cloudflare Workers + Durable Objects + D1)
- ลานประลองออนไลน์: สุ่มคู่ (แสดงจำนวนคนในคิว) ไม่มีบอท 2 โหมด คณิตศาสตร์ / ความรู้รอบตัว ชนะ +5 EXP แพ้ 0
- อันดับรายสัปดาห์: พิชิตดันเจี้ยนมากสุด / ชนะประลองมากสุด รีเซ็ตวันจันทร์ 00:00
- เข้าสู่ระบบด้วย Google (ไม่บังคับ) และย้ายตัวละครจากเครื่องขึ้นบัญชี

## โครงไฟล์
- `js/qc-*.js`, `css/questclass.css`: ส่วนที่นำมาจาก QuestClass RPG (กติกา, ตัวสร้างโจทย์, สไปรต์, ฉาก, UI พื้นฐาน)
  - แก้จากต้นฉบับ 1 จุด: `qc-scenes.js` ใช้ path รูปพื้นหลังแบบเต็ม
- `js/dojo-store.js`: กติกาของ QuestDojo + ที่เก็บข้อมูลผู้เล่น
- `js/dojo-app.js`, `css/dojo.css`: หน้าจอทั้งหมด
- ไฟล์ static ล้วน ไม่ต้อง build ยังปิดไม่ให้ search engine เก็บ (`noindex`, `_headers`, `robots.txt`)
